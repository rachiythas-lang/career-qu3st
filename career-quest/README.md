# 🎓 Career Quest: เส้นทางสู่อาชีพและการเงิน

**Online Multiplayer Educational Board Game**

เล่นพร้อมกันแบบ Real-time กับเพื่อนได้!

## วิธีรัน

```bash
cd career-quest
node server/index.js
```

เปิดเบราว์เซอร์ที่ **http://localhost:3000**

## วิธีเล่นออนไลน์กับเพื่อน

1. คนที่เป็น Host กด **สร้างห้อง** → ได้รหัสห้อง (เช่น AB29XZ)
2. ส่งรหัสให้เพื่อน
3. เพื่อนกด **เข้าร่วมห้อง** ใส่รหัส + ชื่อ
4. Host กด **เริ่มเกม** เมื่อครบจำนวน
5. เลือกอาชีพ → ทอยลูกเต๋า → จัดการเงิน ออม ลงทุน พัฒนาทักษะ
6. เล่นครบ 12 รอบ → สรุป Success Score ผู้ชนะ!

## เทคโนโลยี

- Backend: Pure Node.js (HTTP + Server-Sent Events)
- Frontend: HTML/CSS/JS
- ไม่ต้องติดตั้ง npm packages เพิ่ม — รันได้เลยด้วย Node.js

## ระบบคะแนน (Success Score)

| หมวด | คะแนน |
|------|-------|
| เงินออม | 40 |
| อาชีพ (Level) | 30 |
| ทักษะ | 20 |
| คุณภาพชีวิต | 10 |
| **รวม** | **100** |

ผู้ที่มีคะแนนสูงสุดชนะ ไม่ใช่คนที่มีเงินมากที่สุด
